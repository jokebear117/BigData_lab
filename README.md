# BigData_lab

Labs for the course *Introduction to Big Data*.

| Week | Topic | Folder |
|---|---|---|
| 3 | Finding similar items | `w03-lsh/` |
| 4 | Mining data streams | `w04-stream/` |
| 5 | Link analysis | `w05-pagerank/` |
| 6 | Frequent itemsets | `w06-apriori/` |
| 7 | Clustering | `w07-kmeans/` |

Each week folder contains its requirements, task code, measurements, and
submission notes. Run `python3 test_tasks.py` from a week folder to check its
implementation. Submission artifacts are under that folder's `out/` directory.
